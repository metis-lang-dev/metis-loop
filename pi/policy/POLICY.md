
## The pattern catalog

`policy/skills/patterns/` (the same text as `skills/metis-loop/patterns/`, the Claude Code seat's) is the catalog of metis language and loop usage patterns: 39 named patterns in seven categories, each with the situation, the shape, a real example and `Loop:` how the pi agent recognizes and applies it. Give it to the pi agent beside the phase skill (`--skill`, or the prompt's skill slot): a candidate drafted without the catalog's `Loop:` lines repeats the anti-patterns listed in its README (the faked class, the timer in disguise, the negated premise, the compensating rule).
