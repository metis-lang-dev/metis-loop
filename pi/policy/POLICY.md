
## The pattern catalog

`policy/skills/patterns/` (the same text as `skills/metis-loop/patterns/`, the Claude Code seat's) is the catalog of metis language and loop usage patterns: named patterns in seven categories, each with the situation, the shape, a real example and `Loop:` how the pi agent recognizes and applies it. It is NOT passed with `--skill`: `driver.py --skill` puts one file into every prompt, and the catalog is 72 KB (about 18k tokens a call), and `propose.py` has no skill slot. The pi seat has file tools and opens the category it is in on demand; a driver brain without file tools gets at most the README's anti-pattern list, written for it. A candidate drafted without the catalog's `Loop:` lines repeats the anti-patterns listed there (the faked class, the timer in disguise, the negated premise, the compensating rule).
